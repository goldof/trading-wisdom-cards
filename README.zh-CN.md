# JX 华尔街家训卡

30 张编号交易纪律卡，提炼自**陈江挺《炒股的智慧》**——每卡一个**最小自解释单元**：编号、一句话家训（尽量用原话压缩）、出处、证伪条件、边界（不适用）。

**出处声明**：全部家训均为陈江挺《炒股的智慧》一书原话的压缩引用——JX01–JX14 出自第五章第一节"华尔街的家训"，JX15–JX30 出自全书扫描（按 5 条公开发布的列入标准筛选）。短引用、每卡注明出处。

任意一张卡（图片或文字）丢给任意大模型，它都能解释展开。无需安装 skill。

## 这是什么（不是什么）

这是**防反悔工具，不是荐股**。它盯持卡人，不盯行情：

- **提醒 ≠ 建议**。破线时，工具只把持卡人当初亲手写下的原话递回来——绝不输出买卖判断、评级，不给"割 / 不割"选项。
- 每卡只描述**"违背这条家训长什么样"**（证伪条件：可观测、可判定，到期是非分明），供持卡人自查。
- 每卡必带**"不适用"**行：边界的诚实声明。有损压缩必须声明损了什么——删了它，压缩变欺骗。
- 卡片不做该买该卖的判断。

## 列入标准（增减以此为准）

1. **可行动**：指导具体的买卖 / 持仓 / 资金行为。纯知识、品格修养不列入。
2. **可证伪**：能写出"违背长什么样"，过三问——口径可被规避吗？归因可分离吗？到期能是非分明判定吗？
3. **普适**：不限于单一个股、一时一地。
4. **非重复**：与已有卡无实质重叠；互补可并存，但须在卡中注明互补关系。
5. **有出处**：书中原话可溯，压缩不走样。

5 条任一条不满足即不列入；"可立可不立"的不立。
